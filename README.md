# 拾衡 · 校园饮食与运动智能体

拾衡把高校学生的用餐预算、校园菜单参考、训练计划和每日记录放在同一网页。默认打开上外松江校区。点击「吃饭 → 上外菜单参考」可浏览菜单快照。选择「记录已吃」后，可在能量页查看当天摄入。

本仓库为 GitHub Pages 静态体验版。小拾使用浏览器本地规则生成计划，照片仅在本机预览，附近搜索可跳转地图。档案及记录保存在当前浏览器。

菜单快照采集于 2026-11-04。菜名与价格来自该次快照，营养为估算。图片为菜型示意。照片来源及许可见 [第三方内容说明](THIRD_PARTY_NOTICES.md)。

本地预览可在仓库根目录运行 `python3 -m http.server 8000 --bind 127.0.0.1`，然后打开 http://127.0.0.1:8000/ 。
